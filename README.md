# Tassel

Canvas and StudentVUE in one Mac app: what's due, what's missing, grades, messages and your class schedule.

## Download

**[Download the latest Tassel](https://github.com/Xcissors280/Tassel-Releases/releases/latest/download/Tassel.zip)**

1. Unzip it and move **Tassel** into your **Applications** folder. If your Mac asks for an administrator password,
   use the **Applications** folder inside your home folder instead (make one if it isn't there); Tassel works the same
   from either and never needs an administrator.
2. The first time you open it, macOS says it can't check Tassel for malware. Click **Done**, then go to
   **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only do this once.
3. In **Settings → Accounts**, add your school's Canvas (and StudentVUE if your school uses it).

Tassel updates itself: when there's a new version it asks to install it (or does it automatically if you turn that on
in Settings → General), then relaunches. **Tassel → Check for Updates…** checks right away.

Requires macOS 26 or later. Tassel is invite-only for now: your school email has to be on the access list.
